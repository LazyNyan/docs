This will walk you through setting up Pear Desktop for the widget.

- Download and install [Pear Desktop](https://github.com/pear-devs/pear-desktop/releases/latest) from their GitHub page

- Open it if you haven't already, and click **Plugins** at the top left
- Find the plugin called `API Server [Beta]`.
  - If it's not already enabled (and you don't see a right arrow next to it) click to enable it!

Now go to the [widget setup page](https://music.nyako.cat/setup), click YouTube Music & leave everything as default. Then you can click Request Authorization.

Once you've gotten it, you can go on to customizing the widget to your liking!
