Cider is a paid app ($3 USD) and requires an Apple Music subscription.

In Cider, open **Settings** -> Connectivity -> Manage External Application Access to Cider.

Create a new API token, select **Apple Music** on the [setup page](https://music.nyako.cat/setup), paste your token and authorize.

If you don't want to pay (reasonably so), you can use the other music players method with the Apple Music app from the Microsoft Store.

Once you've gotten it, you can go on to customizing the widget to your liking!
