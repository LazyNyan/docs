You will need to make sure you have/can access a few things before using the overlay!

## Prerequisites

- The *music service* you will be playing/streaming music from. This can be either a website or a program on your computer (like foobar)
  - **Not all are made equal!** The source you use determines how the widget gets song info
- Your streaming software/widget destination of choice (most likely OBS)
- A functional browser (anything should work rlly) 
- Ability to read; if you're reading this you can read, congratulations.
- Patch notes: Removed herobrine

Once you have all of those, move on the next step!
