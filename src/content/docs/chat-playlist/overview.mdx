Nyan's Chat Playlist is an unreleased personal widget to manage song requests from Twitch chat. 

## Supported Streaming/Music Platforms

Twitch chat is the only streaming site intended to be supported as it is the most widely used, but this may change in the future to include Kick.

Spotify will **never** be supported due to their aggressive API changes during the past several months. If you really need spotify try out [Songify](https://songify.rocks/) instead.
